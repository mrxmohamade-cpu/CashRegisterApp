# FashionHub - متجر إلكتروني احترافي (RTL)

متجر إلكتروني كامل لبيع الملابس ومنتجات أخرى، متجاوب بالكامل مع جميع الشاشات ويدعم العربية RTL.

## التقنية المستخدمة
- Node.js + Express + EJS
- SQLite (قاعدة بيانات ملفية جاهزة)
- واجهة حديثة Responsive + RTL

## المميزات
- الصفحة الرئيسية: سلايدر/قسم عروض + منتجات مميزة + أحدث المنتجات.
- صفحة منتجات مع فلترة حسب السعر/القسم/المقاس/اللون + ترتيب.
- صفحة تفاصيل المنتج مع صور متعددة + اختيار المقاس/اللون.
- نظام طلب بدون دفع إلكتروني (الدفع عند الاستلام فقط).
- حفظ الطلبات في قاعدة البيانات.
- لوحة تحكم المدير:
  - إدارة المنتجات (إضافة/حذف/تفعيل/تعطيل + صور متعددة)
  - إدارة الأقسام
  - إدارة الطلبات وتغيير الحالة
  - البحث برقم الهاتف
  - إحصائيات أساسية
- أمان:
  - تسجيل دخول مدير فقط
  - تشفير كلمة المرور (bcrypt)
  - CSRF protection
  - Rate Limiting لمنع السبام
  - Helmet headers

## النشر على استضافة
### 1) استضافة Node.js (cPanel/Cloud/VPS)
1. ارفع ملفات المشروع كاملة.
2. نفّذ:
   ```bash
   npm install --production
   npm run init-db
   npm start
   ```
3. اربط الدومين مع البورت (reverse proxy من Nginx/Apache).
4. فعّل PM2 للإبقاء على التطبيق يعمل:
   ```bash
   npm i -g pm2
   pm2 start src/server.js --name fashionhub
   pm2 save
   ```

### 2) استضافة مشتركة لا تدعم Node مباشرة
- استخدم VPS صغير أو خدمة Node managed (Render/Railway) لجزء التطبيق.
- أو اطلب من مزود الاستضافة تفعيل Node App Manager.

## ملاحظات
- قاعدة البيانات موجودة تلقائياً في `src/data/store.db` بعد أول تشغيل.
- صور المنتجات تُحفظ في `src/public/uploads`.
- لا توجد أي بوابة دفع إلكترونية؛ الطلبات Cash on Delivery فقط.
